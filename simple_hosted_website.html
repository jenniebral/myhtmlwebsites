How to host

  1. Save this file as index.html.
  2. Test locally: python3 -m http.server 8000 then open http://localhost:8000.
  3. Push to a new GitHub repo and enable GitHub Pages (branch: main or gh-pages).
  4. Or drag-and-drop the index.html file into Netlify's Sites dashboard ("Sites > New site from Git").
  5. Or deploy with Vercel by importing the repo — it will auto-detect a static site.
